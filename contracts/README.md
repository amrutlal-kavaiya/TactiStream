# Contracts

Canonical JSON Schemas (draft 2020-12) for every record that crosses a boundary: simulator → bus,
bus → state, state → agents, agents → UI, recap → studio graphics. Constitution principle IV.

| Schema | Producer | Consumers |
|---|---|---|
| `common.schema.json` | — | all (shared `$defs`) |
| `match_metadata.schema.json` | simulator | state, UI, Fabric |
| `event.schema.json` | simulator / future adapters | state, metrics, agents (via tools), UI, Fabric |
| `tracking_frame.schema.json` | simulator / future adapters | state, metrics, 3D replay |
| `metric_result.schema.json` | metric engine | moments, agents, evidence drawer |
| `candidate_moment.schema.json` | moment detector | agent workflow, timeline, recap |
| `claim.schema.json` | Analyst / Verifier / Producer | workflow, output checks, trace view |
| `insight_packet.schema.json` | workflow (after output checks) | UI, recap, Fabric |
| `recap.schema.json` | recap builder | UI, export |
| `feed_envelope.schema.json` | any FeedBus publisher | Event Hubs consumers, Fabric Eventstream |
| `ws_message.schema.json` | API WebSocket | frontend |
| `latency_sample.schema.json` | `LatencyRecorder` (API), 008 runners | App Insights logs, Fabric `Latency`, 008 |
| `agent_trace.schema.json` | agent workflow (`TraceRecorder`) | trace API, agent trace view, Fabric `agent_traces`, 008 |

Rules:

- `examples/*.json` MUST validate; `backend/tests/contract/` checks every example against its schema and round-trips it through the matching Pydantic model.
- TypeScript types in `frontend/src/contracts/generated.ts` are generated by `npm run contracts:gen` (json-schema-to-typescript); CI fails if regeneration produces a diff.
- Changing a schema: bump `schema_version` minor for additive changes, major for breaking ones; update examples and both language bindings in the same commit.
