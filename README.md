# TactiStream

See the move behind the moment.

TactiStream turns a synthetic football event and tracking feed, streamed live, into evidence-backed tactical stories. A deterministic
match engine ingests the feed, computes explainable metrics and picks the moments worth explaining; a bounded set of
agents (Analyst, Verifier, Producer) turns them into short cards in which every number, name and timestamp links back
to the event, frame or metric it came from. If a claim cannot be supported it is blocked, and if the model is slow the
viewer gets a plain factual card instead. Tactical readings are labelled "Interpretation", never presented as fact.

**Status:** walking skeleton (feature 001). One synthetic pass travels feed → state → metric → WebSocket → browser and
appears as a deterministic factual card with working evidence links. The agents, simulator, 3D replay and
personalization arrive in later features; see the [roadmap](specs/README.md).

> **Synthetic data.** Every match, team and player in TactiStream is fictional (teams "Blue" and "Amber"): hand-authored
> fixtures in the walking skeleton, generated by the project's own simulator from feature 002 onward. No real players, clubs, competitions or official data feeds are used or implied,
> and the UI shows a persistent "Synthetic" source badge on every match.

## Quickstart

Prerequisites: [uv](https://docs.astral.sh/uv/) ≥ 0.5 and Node 22. Azure is only needed for the optional smoke tests.

```bash
cp .env.example .env    # defaults: in-memory bus, agents off, no Azure
make install            # backend deps, frontend deps, Playwright Chromium (+ system libs; may ask for sudo)
make dev                # API on :8000, UI on http://localhost:5173
```

Open http://localhost:5173 and press **Start demo match**. Within a few seconds a factual card appears for a forward
pass; click an evidence chip such as `evt-0042` to see the raw record behind it.

Full walkthrough, settings and the Azure smoke checks:
[specs/001-walking-skeleton/quickstart.md](specs/001-walking-skeleton/quickstart.md).

## Tests

```bash
make lint        # ruff, ruff format --check, mypy (strict); eslint, tsc
make test        # backend pytest (live Azure tests excluded) + frontend vitest
make contracts   # contract tests, regenerate TS types from /contracts, fail on drift
make e2e         # Playwright smoke: built frontend served by the real backend (port 8000 must be free)
```

CI (`.github/workflows/ci.yml`) runs the same checks as four jobs: `backend`, `frontend`, `contracts`, `e2e`.
